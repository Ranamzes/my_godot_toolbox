# Godot Project Initializer

Этот скилл предназначен для быстрой, профессиональной и надежной инициализации новых проектов на игровом движке **Godot 4** (начиная с версии 4.0 и выше). Он поддерживает автоматическое создание структуры каталогов, слияние настроек пресетов (`base`, `2d`, `jam`), установку синглтонов автозагрузки, а также подготовку проекта под интеграцию с ИИ-редактором через **Godot-MCP**.

---

## 1. КРИТИЧЕСКОЕ ПРАВИЛО: Интерактивный опрос перед инициализацией

Ты **ОБЯЗАН** начать работу с проведения короткого интерактивного опроса пользователя. **ЗАПРЕЩЕНО** запускать скрипты инициализации вслепую, не обсудив проект с пользователем.

Сформулируй дружелюбный опрос на русском языке, задав следующие вопросы (можешь адаптировать их под контекст, если пользователь уже частично описал игру):
1. **Описание игры**: "Расскажи в двух словах о своей будущей игре (жанр, ключевая идея)."
2. **Визуальный стиль и пресеты**: "Какой будет визуал? Если это 2D-пиксель-арт, мы применим пресет `2d` со специальными настройками сжатия, Nearest-фильтрации текстур и Pixel Snap. Если это классический проект, мы настроим базовый рендеринг."
3. **Пресет для Game Jam**: "Планируется ли участие в джеме? Если да, мы подключим пресет `jam`, который настроит стандартную раскладку управления (WASD + Стрелки + Пробел + Действие), менеджер плавного переключения сцен (`SceneManager`) и менеджер звуков (`SoundManager`)."
4. **Интеграция с Godot-MCP (ИИ-редактор)**: "Хочешь ли ты сразу установить плагин `godot_mcp`? Это позволит мне в будущем видеть структуру твоих сцен, добавлять и настраивать ноды, а также редактировать GDScript прямо из нашего чата, когда проект открыт в редакторе Godot."
5. **Системы из Toolbox**: "Нужно ли перенести какие-то готовые системы из твоей библиотеки `my_godot_toolbox` (например, `footstep_system`)? Это можно будет сделать сразу после инициализации."

## 2. Процесс инициализации (Для Агента)

После того как пользователь ответил на вопросы и вы утвердили конфигурацию:

### Шаг 1: Запуск скрипта инициализации
Вызови скрипт `initialize.py` с нужными параметрами. Скрипт находится по пути:
`my_godot_toolbox/.agent/workflows/godot-project-initializer/scripts/initialize.py`

Пример вызова для 2D-игры для джема с поддержкой Godot-MCP:
```bash
python3 my_godot_toolbox/.agent/workflows/godot-project-initializer/scripts/initialize.py \
  --path /Users/remart/Projects/games/my_new_game \
  --presets base,2d,jam \
  --mcp
```

### Параметры скрипта:
* `--path`: Абсолютный путь к папке проекта. Папка будет создана, если её нет.
* `--presets`: Перечисление пресетов через запятую (`base`, `2d`, `jam`).
* `--mcp`: Флаг. Если указан, скрипт автоматически скачает с GitHub плагин `ee0pdt/Godot-MCP`, установит его в `addons/godot_mcp` нового проекта и активирует его в `project.godot`.

### Шаг 2: Проверка файлов
Убедись, что:
1. Создан файл `project.godot`.
2. Создана правильная структура папок (`src/autoloads/`, `scenes/`, `scripts/`, `assets/`).
3. Созданы `.gitignore` и `.gitattributes`.
4. В папке `src/autoloads/` лежат GDScript синглтоны (такие как `event_bus.gd`).

### Шаг 3: Объяснение структуры пользователю
После завершения инициализации кратко расскажи пользователю на русском языке, какая структура была создана, какие синглтоны зарегистрированы (например, `EventBus` для событий, `SceneManager` для переходов, `SoundManager` для аудио) и как запустить проект.

Если был установлен Godot-MCP, напомни пользователю:
> "Я установил и включил плагин **Godot-MCP** в проекте. Открой этот проект в редакторе Godot 4. Как только ты его откроешь, я смогу использовать MCP-инструменты `godot-editor` для непосредственной работы со сценами, создания нод и настройки логики!"

## 3. Спецификация пресетов и синглтонов

### Base Preset
* Создает чистую и модульную структуру.
* Регистрирует синглтон **`EventBus`** (`res://src/autoloads/event_bus.gd`). Используй его для событийно-ориентированной архитектуры.
* Создает `.gitignore` (скрывает кэш редактора `.godot/`) и `.gitattributes` (для Git LFS).

### 2D Preset
* Переключает рендеринг на `gl_compatibility` (идеально для пиксель-арта и старых видеокарт/мобильных устройств).
* Устанавливает текстурный фильтр по умолчанию в `Nearest` (чтобы пиксели оставались четкими, без размытия).
* Включает `snap_2d_transforms_to_pixel` и `snap_2d_vertices_to_pixel`, чтобы избежать дрожания пикселей при движении камеры.

### Jam Preset
* Прописывает стандартную игровую раскладку клавиш WASD + Стрелки (`move_left`, `move_right`, `move_up`, `move_down`), Пробел (`jump`) и E/ЛКМ (`action`).
* Копирует синглтон **`SceneManager`** (`res://src/autoloads/scene_manager.gd`) для плавных переходов между сценами с помощью метода `SceneManager.change_scene("path")`.
* Копирует синглтон **`SoundManager`** (`res://src/autoloads/sound_manager.gd`) для воспроизведения SFX и музыки из пула одной строчкой кода (например, `SoundManager.play_sfx(sound_resource)`).
